# UIgly

An intentionally ugly collection of UI templates. Every template is a standalone HTML file with plain CSS, so you can open it directly in a browser and copy its source.

## Templates

| Template | Category | Preview source |
| --- | --- | --- |
| Typo login | Copy | [`templates/typo-login/index.html`](templates/typo-login/index.html) |

The gallery is published at [m4n9o.com/project/uigly](https://m4n9o.com/project/uigly). Templates are listed in [`templates/catalog.json`](templates/catalog.json).

## Contribute

Fork this repository, add `templates/<slug>/index.html`, add its title and description to `templates/catalog.json`, and open a pull request. Please read [CONTRIBUTING.md](CONTRIBUTING.md) for the format and review criteria.

The templates are licensed under MIT. Keep them original and self-contained.
